# UI/UX Guidelines

The application must look clean, simple, modern, and professional.

## Visual Style

Use:

- Soft background
- White cards
- Rounded corners
- Subtle shadows
- Good spacing
- Clear typography
- Calm colors
- Clear button states

Avoid:

- Too many colors
- Heavy animations
- Complex layouts
- Dense screens
- Visual noise

## Layout

The content must be centered.

Use a maximum content width around 900px.

The interface must work well on:

- Mobile
- Tablet
- Desktop

## Question Screen

Each question screen must show:

- App title
- Progress information
- Question number
- Question group
- Question image, when available
- Question text
- Answer options
- Navigation buttons

## Result Screen

The result screen must show:

- Total questions
- Answered questions
- Correct answers
- Wrong answers
- Pending answer-key questions
- Unanswered questions
- Score percentage
- Review table

## Status Colors

Use these statuses:

- Correct: green
- Wrong: red
- Pending answer key: amber
- Unanswered: gray

Always include text labels together with color indicators.
