# Project Context

The project is a React application for validating TVDE exam responses.

The user will answer TVDE exam questions one by one. Each question may contain:

- Question number
- Question ID
- Group/category
- Question text
- Image
- Multiple-choice options
- Correct response letter
- Correct response text

The application must help the user practice for the TVDE exam in a clean, simple, and focused way.

The goal is not to create a complex learning platform. The goal is to create a lightweight, beautiful, and easy-to-use response validator.
