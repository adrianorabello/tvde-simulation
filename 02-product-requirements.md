# Product Requirements

The application must:

1. Display one question at a time.
2. Show the question image when available.
3. Allow the user to choose one answer.
4. Save progress locally.
5. Validate answers against the answer key.
6. Show if the answer is correct, wrong, pending answer key, or unanswered.
7. Show a final result screen.
8. Provide a review table after finishing the test.
9. Work well on desktop and mobile.
10. Be simple, clean, and pleasant to use.

The application must not:

- Require authentication.
- Require backend integration initially.
- Use unnecessary libraries.
- Have a noisy or overloaded interface.
