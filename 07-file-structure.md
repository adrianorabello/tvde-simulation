# Expected File Structure

Create the application using this structure:

```txt
tvde-response-validator/
├── package.json
├── index.html
├── vite.config.ts
├── tsconfig.json
├── tsconfig.node.json
├── .gitignore
├── .prettierrc
├── eslint.config.js
└── src/
    ├── main.tsx
    ├── App.tsx
    ├── styles.css
    ├── data/
    │   └── questions.json
    ├── types/
    │   └── quiz.types.ts
    ├── utils/
    │   └── quiz.utils.ts
    └── components/
        ├── Header.tsx
        ├── Layout.tsx
        ├── ProgressBar.tsx
        ├── QuestionCard.tsx
        ├── OptionButton.tsx
        ├── ResultSummary.tsx
        └── ReviewTable.tsx
```
